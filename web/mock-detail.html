session-banner

cli agents terminal

Prints a one-line banner at the start of every session: agent name, current working directory, branch, and how long this session has been running. Useful when you've got three terminal panes open and forgot which one is claude-code, which is codex, and which is just your shell.

What it prints

[claude-code] ~/code/hooks  feature/directory-redesign  3m

The banner fires on SessionStart. Codex is pinned to the startup|resume matcher so re-running on /clear doesn't double-print.

Configuration

No config. The banner script reads the environment variables the agent already sets (CLAUDE_SESSION_ID, CODEX_SESSION_ID) and falls back to a sensible default if neither is present.

Override examples

Want a different format on Codex? Set an agent override in your package manifest: 

{
  "id": "print-banner",
  "event": "SessionStart",
  "command": "node $HOOK_DIR/banner.mjs",
  "agents": { "codex": { "matcher": "startup|resume" } }
}

Uninstall

Run npx hooks remove session-banner. The hook is removed cleanly from both ~/.claude/settings.json and ~/.codex/hooks.json, and the script directory is garbage-collected.
